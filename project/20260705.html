03市场前瞻

短期分析（未来1-2周）

周末新闻流呈现"地缘风险升温 + 存储景气强化 + 美元走弱"三线并行格局。霍尔木兹海峡阿曼航道船舶锐减、梅德韦杰夫警告曼德海峡、OPEC+周日会议三大事件叠加，油价与油运板块短期具备地缘溢价上行空间；但若OPEC+如期上调配额、霍尔木兹通行恢复，溢价可能快速回吐。江波龙H1业绩预告+622倍、三星Q3提价20%、野村确认短缺三重利好，存储芯片链基本面强化但需警惕高位筹码松动——上周9只科技股主力净流出520亿元即为前车之鉴。美元创12周最大单周跌幅、离岸人民币6.7858、黄金4125美元，外资回流新兴市场为A股与港股提供顺风。7月6日（周一）开盘关注：OPEC+会议结果、霍尔木兹海峡最新通行数据、江波龙业绩预告后存储板块开盘反应、本周CFTC持仓报告（7月7日周二公布）。预计上证指数4,000-4,100点区间震荡，恒指23,000-23,800点，结构性机会优于趋势性机会。

行业展望

存储芯片链是当下产业景气最确定的细分赛道：江波龙H1业绩预告+622~744倍、三星Q3提价20%、野村确认短缺未顶、瑞银上调DDR Q3合约价至+32%，A股存储模组直接受益，但需精选业绩兑现确定性高的龙头。油运与油气开采受益于霍尔木兹阿曼航道船舶锐减、梅德韦杰夫警告曼德海峡、高盛警告若封锁延续布伦特全年均价破100美元三重催化，中国海油、招商轮船、中远海能具备地缘溢价空间。黄金与高股息银行H股是当前最具防御属性的配置：摩根大通看Q4金价至4,500美元、平安继续增持农行H股至26%，险资"哑铃式"配置示范效应明显。欧洲空调出口是银河证券新催化剂：厄尔尼诺致欧洲高温、中国是欧盟进口空调最大来源国、后续排产数据或上调，海尔智家、美的集团直接受益。港股互联网龙头南向资金持续净买入，美团本周净买入86亿港元居首，腾讯7月3日回购5.01亿港元，估值修复行情延续。纯AI概念股短期需警惕：上周光模块三剑客周跌21%、主力净流出近190亿元，资金兑现压力未释放完毕。

前瞻性推测（未来一周链式推演）

推演一（地缘溢价路径）：若OPEC+周日会议仅小幅上调配额18.8万桶/日 + 霍尔木兹阿曼航道船舶延续锐减 + 梅德韦杰夫警告发酵 → 布伦特原油有望突破78美元，中国海油(600938/00883)、招商轮船(601872)、中远海能(600026)地缘溢价延续；若伊朗进一步限制通行，油价可能冲击85美元，油运股运价弹性更大。

推演二（存储业绩兑现路径）：若江波龙H1业绩预告点燃存储板块情绪 + 三星Q3提价20%落地 + 野村报告发酵 → 江波龙(301308)有望突破前高646元、兆易创新(603986)延续历史新高趋势；但需警惕高位筹码松动，若开盘高开超8%建议分批建仓而非追高。

推演三（避险防御路径）：若美元指数延续走弱 + 7月7日CFTC持仓显示黄金投机净多头继续回升 + 7月9日Ecofin会议释放欧央行鸽派信号 → 金价有望突破4,265美元，黄金ETF(518880)与紫金矿业(02899)联动上行，紫金矿业港股突破前高32港元可期；同时高股息银行H股配置价值延续。

推演四（AI资金切换路径）：若光模块三剑客主力流出延续 + 英伟达云业务分成新模式发酵 + 7月15日豆包/千问智能体下线 → 资金从AI概念股切换至存储模组、半导体设备等"卖铲人"，江波龙、兆易创新相对收益显著；纯AI概念股短期建议低配。

推演五（欧洲空调出口路径）：若欧洲高温延续 + 银河证券研报发酵 + 后续空调排产数据上调 → 海尔智家(600690)、美的集团(000333)出口链估值修复，可关注空调出口占比高、欧洲渠道布局深的龙头。

调整结论与历史审视：本次分析相较7月4日判断作四点调整——(1)维持存储芯片链"超配"，江波龙H1业绩预告+622倍、三星Q3提价20%、野村确认短缺三重确认，但标的从"江波龙+中微公司"调整为"江波龙+兆易创新"，因兆易创新利基存储属性更纯粹、中微公司本周资金流出压力大；(2)新增油运/能源"超配"，霍尔木兹阿曼航道船舶锐减+梅德韦杰夫警告曼德海峡+OPEC+周日会议三重地缘催化，新增中国海油(600938)与港股中国海洋石油(00883)；3)新增欧洲空调出口"关注"，银河证券研报+厄尔尼诺+中国是欧盟最大空调来源国，新增海尔智家(600690)；(4)移出三花智控、中微公司、券商ETF，因人形机器人主题炒作后回调风险、半导体设备短期资金压力、券商板块催化不足；(5)维持纯AI概念股"低配"，上周520亿资金撤离9只科技股、光模块三剑客周跌21%；(6)维持黄金+高股息银行H股"超配"，美元走弱+摩根大通看涨+平安增持农行三重逻辑共振未变。

05常见问题预解答

若霍尔木兹海峡局势进一步升级，应如何调整配置？
若霍尔木兹阿曼航道船舶延续锐减且伊朗进一步限制通行，建议三步调整：第一步加仓中国海油(600938/00883)、招商轮船(601872)、中远海能(600026)等地缘溢价受益标的；第二步加仓黄金ETF(518880)与紫金矿业(02899)避险；第三步减仓纯AI概念股与高估值科技股，因油价飙升可能推升美国通胀预期、压制成长股估值。但若OPEC+周日会议大幅上调配额(超30万桶/日)或霍尔木兹通行快速恢复，应反向操作。建议设置明确的止损纪律，能源类个股止损位参考表中数据。
存储芯片板块上周遭主力抛售520亿元，为何仍维持"超配"？
核心原因在于产业景气与短期资金博弈的背离。江波龙H1业绩预告归母净利92-110亿元、同比+622~744倍，已用业绩兑现证明存储涨价周期的盈利弹性；三星Q3 DRAM拟提价20%、野村确认供应短缺未顶、瑞银上调DDR Q3合约价至环比+32%，产业景气度进一步强化。上周主力净流出520亿元更多是高位筹码松动与板块轮动，而非基本面恶化。但需注意：① 短期波动加大，建议分批建仓而非一次性买入；② 精选业绩兑现确定性高的龙头(江波龙、兆易创新)，回避纯主题炒作个股；③ 设置严格止损(江波龙540元、兆易创新680元)控制下行风险。
美元走弱趋势能否延续？对港股配置有何影响？
美元走弱趋势短期有望延续但空间有限。美国6月非农大幅不及预期、市场下调美联储9月加息概率至约45%、美元指数创12周最大单周跌幅，三者形成共振；但美国经济基本面仍强于欧日、特朗普"美国例外论"政策基调可能支撑美元中期韧性。对港股配置的影响：① 离岸人民币升值至6.7858、本周累涨190点，外资回流新兴市场为港股提供顺风；② 南向资金本周净买入超149亿港元，加仓美团86亿、比亚迪38亿、建行30亿、石药27亿；③ 港股互联网龙头(腾讯、美团)与高股息(银行H股、中海油)双主线受益于汇率与资金面共振。建议维持港股通5只推荐组合，但若美元指数反弹突破102，可阶段性减仓高Beta标的。
