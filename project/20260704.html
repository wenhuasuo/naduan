03市场前瞻

短期分析（未来1-2周）

美国非农数据弱化短期加息预期，美元创12周最大单周跌幅，人民币被动升值，外资回流新兴市场为A股与港股提供顺风。但7月4日上证虽续涨0.32%、创业板却跌0.36%，市场风格阶段性切向银行、公用事业、电力等低位价值板块，资金分歧加大、高位科技股冲高回落是短期最显著的特征。本周主力净流出1,922亿元但汽车零部件、化学制药逆势净流入，反映资金正沿"业绩兑现 + 政策受益"两条主线做高低切换。下周关注：7月7日（周二）CFTC持仓报告、7月9日欧元集团会议与拉加德亲自出席Ecofin、7月9日比亚迪古德伍德速度节首发腾势、7月10日莫迪访新、7月15日豆包/千问智能体功能下线对AI情绪的扰动。预计上证指数4,000-4,120点区间震荡，恒指23,200-23,800点，结构性机会优于趋势性机会。

行业展望

存储芯片链是当下产业景气最确定的细分赛道：三星Q3提价20%、瑞银上调DDR Q3合约价至环比+32%、SemiAnalysis预测2026年底英伟达系统内存占比超30%，A股存储模组、港股代工与封测直接受益。半导体设备受高盛"估值彻底重构"研报与中微公司董事长赴南昌扩产催化，国产替代逻辑强化。人形机器人短期事件密集：特斯拉Optimus产线安装、宇树三大突破预判、三花智控主力净流入31亿，但需警惕主题炒作后回调。黄金与高股息银行H股是当前最具防御属性的配置：摩根大通看Q4金价至4,500美元、平安继续增持农行H股至26%，险资"哑铃式"配置示范效应明显。券商板块半年报预期净利润同比+50%、估值仍处历史低位，是7月业绩验证窗口的胜率品种。商业航天与核电是十五五规划落地与IPO提速的政策受益方向，但题材股波动较大需精选龙头。

前瞻性推测（未来一周链式推演）

推演一：若7月7日CFTC持仓显示黄金投机净多头继续回升 + 7月9日Ecofin会议释放欧央行鸽派信号 → 金价有望突破4,265美元，黄金股与黄金ETF(518880)联动上行，紫金矿业港股突破前高可期。

推演二：若7月15日豆包、千问智能体功能如期下线 + SemiAnalysis内存占比预测发酵 → 市场对AI infra炒作降温但存储基本面强化，资金从AI概念股切换至存储模组、半导体设备等"卖铲人"，江波龙、中微公司、中芯国际相对收益显著。

推演三：若特斯拉Optimus产线安装进度超预期 + 国产机器人三大突破获产业共识 → 人形机器人主题延续但分化加剧，T链核心供应商（三花智控等）跑赢主题ETF；若7月10日莫迪访新促成印新自贸进展 + 中国海警台岛以东常态化执法延续 → 军工/国防板块情绪回暖，可关注航天电器等商业航天与军工交叉标的。

推演四：若7月专项债发行延续6月5,716亿峰值节奏 + "两新"资金加速落地 → 三季度基建链与设备更新链业绩兑现，综合立体交通、能源水利、新型电力系统（核电/储能）成为顺周期beta来源。

调整结论与历史审视：本次分析相较7月3日判断作三点调整——(1)将存储芯片链从"观察"上调至"超配"，因瑞银上调DDR涨幅预期、三星提价口头通知双重确认；(2)将纯AI概念股从"标配"下调至"低配"，因词元经济学指数5月以来跌近20%、豆包与千问智能体下线、SemiAnalysis提示内存挤压AI infra回报率；(3)维持黄金+高股息银行H股"超配"，因美元走弱、摩根大通看涨、平安增持农行三重逻辑共振未变。
